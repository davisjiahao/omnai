# OmnAI v0.3 Host CLI and Package Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Task 9E 的 Host/CLI/包边界：用 durable HostInstall owner 安装四个 Entry Skills，所有 Host/Context 读取认证 Project/Change，CLI 逐命令映射 Section 15.3 exact API，并把 root exports/`.d.ts` 收敛到精确 allowlist。

**Architecture:** Host install先锁 real Home coordinator，再锁 real user-home coordinator，重放 HIT chain/selector，只有 no-PENDING 分支才读取当前包 bundle。CLI 使用 checked-in strict command manifest构造 Commander树；每个成功命令 stdout 是一行 canonical JSON，诊断只到 stderr。包根只显式导出安全 facade/type/pure compiler，不提供 implementation subpath。

**Tech Stack:** TypeScript、Commander、Plan 03 atomic publication、Plans 04–06 public facades、npm pack/install fixtures、TypeScript declaration AST oracle。

**Spec:** 主规范第 13.7 Host reads、15.3–15.5、17 Host precedence、19/9E、20.4、21 Host crash tests 节。

## Global Constraints

- 依赖 Plans 04–06；本计划不得新增绕过 public facade 的 CLI-only store helper。
- Host 安装只支持 `claude|codex|opencode` 和四个 Skills：`omnai`、`omnai-brainstorm`、`omnai-grill`、`omnai-reconcile`。
- CLI mutation必须显式 `--change`，禁止 ACTIVE/slug/directory/positional/defaulted stdin；read locator按规范明确允许 `--active` 或 repeated `--change`。
- CLI 不自动刷新 CAS；首次 token只能来自对应 authenticated read/prepare输出，后续命令使用调用者原样传入。
- stdout一条完整 canonical strict JSON + LF；无 info/debug prose。stderr不得污染成功 stdout。
- Runtime and declaration allowlists are independent exact fixtures；recursive type graph must reject nested Git provider leaks。
