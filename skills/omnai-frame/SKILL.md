# OmnAI Product Framing

1. Run `omnai frame "<idea>"` and read the generated prompt.
2. Establish the target user, painful status quo, specific evidence of demand, and why the current workaround is insufficient.
3. Push back on solution-first framing. Separate the actual problem from the proposed feature.
4. Identify the narrowest valuable wedge and what can be learned from shipping it.
5. Define measurable success signals and explicit non-goals.
6. Update `intent.md` and run `omnai frame --complete` before product-level work proceeds.
