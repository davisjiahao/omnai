# OmnAI v0.3 Full Pipeline Fusion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已批准的 Matt 需求澄清/建模/拆分能力与 Superpowers 的计划、SDD、验证、评审、收尾能力收敛为 OmnAI v0.3 唯一原生流程，并修复所有 Change、Project、Workset、Host 持久化写入的权限完整性问题。

**Architecture:** 以一个严格的 `ChangeAuthorityContext`、一条连续的 `AuthorityEnvelope` 全局链和一个锁定的 `StageAuthorityCatalogV1` 作为唯一机器权限源。Project 创建、Change Genesis、Stage/Run、Evidence、Workspace/Workset 与 Host 安装各自使用可恢复的持久 owner，但所有 Change 内写入都必须进入同一条全局链；流程只支持最终 v0.3，不读取、迁移或兼容 v0.2/中间 v0.3 状态。

**Tech Stack:** Node.js `>=20`、TypeScript `^5.9.2` 严格模式、Zod `^4.1.5`、YAML `^2.8.1`、Commander `^14.0.0`、Node test runner、原生 Git 对象/索引编码、Linux `openat2` + `execveat(AT_EMPTY_PATH)` 受验文件描述符 ABI。

**Spec:** `docs/superpowers/specs/2026-08-22-omnai-v0.3-change-authority-integrity-repair-design.md`
