# OmnAI v0.3 Project Genesis and Global Chain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Task 9D：提供可恢复原子发布能力、Project bootstrap/事务、Change Genesis 以及覆盖所有 top-level owner 的唯一连续 `AuthorityEnvelope` 链。

**Architecture:** Project scope先使用 common-directory Project lock 和严格 ProjectAuthorityContext；bootstrap singleton、ProjectCreationRecord/ProjectMutationRecord 各自有完整 frozen publication。Change 在隐藏 staging 中形成 Genesis 后原子 rename 可见，ProjectConfig CAS 最后完成。Genesis 之后每个 top-level Change owner只增加一个全局 sequence；ordinary Reconcile 作为唯一 nested child，不拥有第二条 sequence。

**Tech Stack:** TypeScript、Plan 02 native Linux binding、atomic rename/fsync、canonical JSON/YAML、Zod、Node child-process crash fixtures。

**Spec:** 主规范第 6、11–13.6、17 Project precedence、19/9D、20.3、21 节。

## Global Constraints

- 依赖 Plans 01–02；不得在本计划发布最终 WorkflowLock 候选。
- Project lock ordering is `Project -> Change`; Workset-held Project seam在 Plan 06 添加。持有 Change lock 时禁止调用 public Project facade。
- 可见 Change 目录只来自一份完整 `TargetChangePublication` 的原子 rename；不能逐文件直接建在最终路径。
- recovery 不重新读取模板、Investigation research、clock、ID allocator 或 package defaults；只使用 frozen payload。
- completed creation retry允许目标 Change出现合法后代和 authored edit，禁止恢复初始 scaffold bytes。

```ts
export function authorityEntryHash(envelope: Omit<AuthorityEnvelope, 'entryHash'>): Sha256 {
  return hashStrictObject(envelope);
}

export function nextEnvelope(input: NextEnvelopeInputV1): AuthorityEnvelope {
  const body = {
    authorityVersion: 1 as const,
    sequence: input.predecessor ? input.predecessor.sequence + 1 : 1,
    predecessorEntryHash: input.predecessor?.entryHash ?? null,
    sourceAuthorityDigest: input.sourceAuthorityDigest,
    targetAuthorityDigest: input.targetAuthorityDigest,
    sourceAuditCursor: input.sourceAuditCursor,
    targetAuditCursor: input.targetAuditCursor,
    operationRequestId: input.operationRequestId,
    requestDigest: input.requestDigest,
    payloadDigest: input.payloadDigest,
  };
  return { ...body, entryHash: authorityEntryHash(body) };
}
```
