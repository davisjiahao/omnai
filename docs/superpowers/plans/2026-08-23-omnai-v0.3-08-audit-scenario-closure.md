> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Task 9F/9G：统一所有 owner 的 exact ordered audit outbox，并让 ordinary Reconcile、Scenario reclassification、operation/recovery/completion/retry 使用同一唯一 terminal target。

**Architecture:** progress 在 context 构造时只读一次；owner payload冻结 expected audit list。PENDING只接受物理 stream 的 exact prefix并追加缺失 suffix，COMPLETED要求 full-list equality。`ordinaryTerminalTarget` 是普通终态唯一编译器；`scenarioReclassificationTarget` 先生成 source/target policy attestations和递归 policy-ref rewrite，再调用同一 ordinary target，并把 nested digest绑定到 Scenario owner。

**Tech Stack:** TypeScript、canonical JSONL、Plan 03 authority chain、Plan 04 Reconcile/Scenario owner、property/crash tests。

**Spec:** 主规范第 13.4–14、19/9F–9G、20.5–20.6、21 phase-four/retry 节。

```ts
export function validatePendingAuditPrefix<T extends StrictJsonValue>(
  actual: readonly T[],
  expected: readonly T[],
): readonly T[] {
  for (let index = 0; index < actual.length; index += 1) {
    if (!strictObjectEqual(actual[index], expected[index])) {
      throw stableError('AUTHORITY_AUDIT_ORDER_MISMATCH');
    }
  }
  if (actual.length > expected.length) throw stableError('AUTHORITY_AUDIT_ORDER_MISMATCH');
  return expected.slice(actual.length);
}
```

Append uses one already-opened progress target under lock and flush barrier; no reread between events.
