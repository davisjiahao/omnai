# OmnAI

OmnAI is a lightweight, repository-local, native AI engineering workflow.

It combines four core disciplines in one coherent workflow:

- **Reality** — recover how an existing codebase actually works.
- **Meaning** — clarify domain language, boundaries, lifecycle, and decisions.
- **Change** — manage requirements, design, revisions, and task dependencies per change.
- **Delivery** — execute incrementally, review independently, and prove completion with fresh evidence.

OmnAI does not depend on HumanLayer, Matt Pocock Skills, OpenSpec, or Superpowers at runtime. It independently implements selected ideas from those workflows and provides optional compatibility import/export later.

The repository is being initialized. The first committed artifact is the OmnAI v0.1 design specification.
