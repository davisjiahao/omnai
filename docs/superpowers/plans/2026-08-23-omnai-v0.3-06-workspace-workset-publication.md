# OmnAI v0.3 Workspace and Workset Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Task 9E 的 Workspace/Workset 部分：建立 Home coordinator、gap-free WOP、严格 registry/workset/reentry v2、逻辑 Git common identity 与 Project authority instance 分离，以及 Core-owned raw Git Worktree publication/recovery。

**Architecture:** Home mutation先锁 `HOME_AUTHORITY_COORDINATOR_V1`，认证 WOP chain，再根据 strict predicate 决定是否需要 Git。Git-backed 新操作在 WOP 前冻结 provider/Project projection；WOP 后按不可跳跃 step lattice发布 reservation、raw branch/admin/.git/index/checkout。跨 Project 操作使用 `Workset -> sorted Project -> sorted Change` lock顺序和 held-authority seam，不递归进入 public Project facade。

**Tech Stack:** TypeScript、Plan 02 Git provider、Plan 03 publication primitives、raw Git object/index-v2 encoder、Zod、Node child process crash tests。

**Spec:** 主规范第 13.7–13.8、15.3 Workset API、17 Workset precedence、19/9E、20.4、20.8、21 Workset certification 节。

## Global Constraints

- 依赖 Plans 02–03；与 Plan 04 并行时不得改共享 domain/catalog/schema 文件。
- WOP replay first stage is provider-free；malformed/gapped owner cannot supply trusted provider binding。
- No production call to `git worktree add/update-ref/read-tree/checkout/reset/prune/remove`；publication uses raw object/ref/admin/control/index bytes only。
- Raw index entries sort by unsigned raw UTF-8 bytes, not locale/UTF-16; support files-backend SHA-1 and SHA-256 only。
- Same logical common Git directory may be registered in two Worksets, but each path-scoped `.omnai` Project has a distinct `projectAuthorityInstanceHash` and lock/reservation identity。
- Public RegisteredProject/Workset/context returns no provider binding or Git executable fields。
