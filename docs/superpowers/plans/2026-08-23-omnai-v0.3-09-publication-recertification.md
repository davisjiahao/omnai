# OmnAI v0.3 Publication and Recertification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Task 9H、重新认证 Task 7/8，并通过 Task 10 独立最终评审：删除遗留路径，冻结唯一 final catalog/compiler/WorkflowLock 字节，经 pre-candidate 与 unchanged-candidate 两道门后使 native v0.3 可发布。

**Architecture:** 第一门在 external native creation仍关闭时验证所有纯 schema/catalog/compiler、writer/export census、owner/recovery和 adversarial性质；通过后从已冻结字节一次性生成 candidate WorkflowLock并开启 certification gate。第二门对同一 candidate执行 clean checkout、packed install、native first-create、real Git/CLI/E2E/crash/full suite。任何 catalog/compiler字节变化使 candidate失效并从第一门重跑。

**Tech Stack:** npm/TypeScript/Node tests、npm pack/install、Git temporary repositories、native syscall trace harness、independent agent code review。

**Spec:** 主规范第 18–26 节，尤其 19/9H、20、21、22、23、24。

## Global Constraints

- 依赖 Plans 01–08 全部完成且聚焦测试全绿。
- Task 1–6 历史不改；Task 7 追加 REOPENED→CLOSED 证据；旧 Task 8 结论保持历史，新 E2E通过后追加 `CERTIFIED`。
- 绝不把旧 report改写成更强声明；所有新结论写新报告/ledger。
- final candidate 只有一份；通过第二门不能生成替代 lock。Catalog/compiler/resource任何 byte变化都删除候选资格并重新跑双门。
- 测试/构建/打包/日志分析与最终 code review 使用独立后台 subagent，主 agent 汇总原始退出码、测试 manifest和发现，不以断连/截断当成功。
- 不 push、不 merge、不 release；本计划只使分支达到可交付状态并向用户提供选择。
